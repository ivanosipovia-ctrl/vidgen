API-ключи

Доступ для внешних приложений. Ключ передаётся заголовком X-Api-Key.

Как вызывать

POST /api/generate
X-Api-Key: vg_ваш_ключ
Content-Type: application/json

{ "model": "omni", "prompt": "зачем видео",
  "duration": 8, "resolution": 720,
  "ratio": "16:9", "audio": true }

GET  /api/jobs            — список задач
GET  /api/jobs/{id}       — статус одной
GET  /api/videos/{id}.mp4 — скачать видео

Задачи, созданные ключом, видны только ему. Веб-интерфейс работает как ключ «web».
