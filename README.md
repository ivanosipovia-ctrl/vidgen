# VidGen — Omni Flash + Seedance 2 Pro

Сайт для генерации видео. Промпт, референсы, длительность, качество, соотношение сторон — как на источнике, но запуск идёт через наш бэкенд.

## Как работает

Каждая генерация:

1. emailnator.com выдаёт свежий временный Gmail
2. под ним регистрируется новый аккаунт на источнике (`http://160.30.161.35`)
3. если загружены референсы — они заливаются в аккаунт как картинки-референсы
4. отправляется команда генерации (та же, что жмёт кнопка Generate на источнике)
5. бэкенд поллит статус, ждёт `done`
6. видео скачивается к нам в `data/videos/` и отдаётся с нашего сайта

Деньги не тратятся: Omni Flash (Veo 3 Free) у источника бесплатный — 5 видео в день на свежий аккаунт, аккаунт новый каждый раз, значит потолка нет.

## Запуск

```
START.bat
```

или

```
node server.js
```

Откроется на `http://localhost:8080` (если порт занят — автоматически `8090`).
Порт и адрес источника переопределяются через `PORT` и `TARGET_URL`.

## Два режима (левая колонка)

- **🎥 Omni Flash** — источник: сервер `🎥 Veo 3 Free` (`server11`), модель `Veo 3.1 Fast`
  - длительность 4/6/8/10 сек → 10 автоматически режется до 8 (предел Veo)
  - 720p, 16:9 / 9:16 / auto
- **⚡ Seedance 2 Pro** — источник: `⚡ Seedance 2.0 24/7` (`server2`)
  - модель: Standard (по умолчанию) / Fast / Lite
  - длительность 5/8/10/12/15 сек, 480p/720p

## Про Seedance честно

Источник отдаёт Seedance 2.0 только с активным пакетом на аккаунте (135K / 265K / подписка). Свежий аккаунт с нулём — получает 400 с текстом про пакет, этот текст мы и покажем в интерфейсе. Обходной путь: файл `data/paid-token.txt` — вставить туда `wtok_...` токен своего аккаунта с пакетом, и все Seedance-запуски пойдут через него (Omni всё равно берёт свежие аккаунты). Токен также читается из переменной окружения `PAID_TOKEN`.

## Файлы

- `server.js` — бэкенд без зависимостей (node 18+, `fetch` из коробки)
- `public/` — интерфейс (промпт, референсы, настройки, история с плеером)
- `data/videos/` — скачанные mp4
- `data/jobs.json` — история запусков
- `tools/` — разведочные скрипты (emailnator, квоты источника, живые тесты)

## API

- `POST /api/generate` — `{model: "omni"|"seedance", targetModel, prompt, duration, resolution, ratio, audio, refs: [{filename, contentType, dataBase64}]}`
- `GET /api/jobs` — список
- `GET /api/jobs/:id` — статус
- `GET /api/videos/:id.mp4` — скачать/смотреть (с Range)
